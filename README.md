# Leandro Canela — Portfolio

Editorial portfolio built with Next.js (App Router), TypeScript, Tailwind CSS v4 and GSAP.

```bash
npm install
npm run dev        # http://localhost:3000
npm run lint
npm run build && npm start
```

## Where things live

| What | File |
| --- | --- |
| Name, role, email, social links, site URL | `src/config/site.ts` |
| Selected projects | `src/data/projects.ts` |
| "What I explore" rows | `src/data/expertise.ts` |
| Design tokens, type scale, motion fallbacks | `src/app/globals.css` |
| Fonts (self-hosted, next/font) | `src/lib/fonts.ts`, `src/fonts/` |
| Sections | `src/components/sections/` |
| Header, footer, ASCII Athens | `src/components/layout/` |
| All GSAP motion | `src/components/motion/MotionController.tsx` |

`NEXT_PUBLIC_CONTACT_EMAIL` and `NEXT_PUBLIC_SITE_URL` override the email and site URL without editing code.

## Content

- **Contact, GitHub, GitLab, CV** — `src/config/site.ts`.
- **Projects** — `src/data/projects.ts` (stastarat.com, Restaurant SaaS, CLI Password Manager).
- **Experience** — `src/data/experience.ts` (Reskillia).
- **Project screenshots** — until supplied, each project shows an engraved schematic plate drawn in code (`src/components/plates/ProjectPlate.tsx`). To use a screenshot, put it in `src/assets/projects/`, import it in `projects.ts` and set `image: { src, alt }`.
- **Site URL** — set `NEXT_PUBLIC_SITE_URL` to the deployed domain so Open Graph links are absolute.
- **Hero artwork resolution** — the supplied landscape is 1672×941. A 2880px-wide version would be sharper on retina screens; replace the files in `src/assets/images/` (same names).

## The ASCII Athens footer

The footer background is real text: a colour ASCII panorama of Athens (Acropolis, Parthenon with its painted frieze, Lycabettus, the city, formulas in the sky). It is generated by a script:

```bash
python3 scripts/generate-athens-ascii.py --print   # needs Pillow
```

It writes the characters to `src/components/layout/athens-ascii.ts` and a tiny colour map (one pixel per character) to `src/assets/ascii/`. The page paints the text with that map through `background-clip: text`, so every character gets its own colour without thousands of spans. There is a wide composition for desktop and a tall one for phones; positions, palette and formulas are at the bottom of the script.

## Notes on decisions

- **Secondary text colour** is `#6B6760` instead of `#77736C`: the original measures 4.4:1 on the page background, just under WCAG AA for small text.
- **Section and project headings** stop growing at their 1440px size, because the content column stops there too; larger values overflowed on wide screens.
- **Hero intro**: the artwork fades in with CSS from the first paint (so the largest image never waits on JavaScript); GSAP runs the text sequence. Hero text waits for the intro only when scripts are available, and a CSS fallback reveals it if they fail.
- **Reduced motion**: with `prefers-reduced-motion`, nothing animates and everything is visible.
